# Экзаменатор 0.9.14 — подготовка к сборке

Этот комплект содержит исходники, а не готовые APK/EXE. Запланирована загрузка изменений в отдельную ветку `qa/examtrainer-0914-build` открытого репозитория Caprifan2078/exam-trainer-android. Исходники в этой ветке станут публичными. Ветка main не меняется, публикации релиза нет.

В workflow `qa-build-0914.yml` предусмотрены независимые задания GitHub Actions: Android debug APK (Gradle, проверка подписи и package) и Windows portable EXE (Electron). Сборка не запускалась, возможны ошибки зависимостей, изменения могут потребовать исправления. На телефоне и Windows запуск не проверен.

Android-версия использует отдельный идентификатор пакета io.github.caprifan2078.examtrainer.qa0914 и тестовую подпись GitHub runner; она не обновляет старую установленную версию и не переносит её черновики. Подпись временная, будущие независимые сборки могут не обновлять тестовый APK. Прежнее приложение удалять не требуется.

Локально прошли тесты full_solve, nmck, statements, independent. Старые оригинальные CI тесты отсутствуют в переданной копии и будут сохранены из базовой ветки репозитория; запуск этого отдельного QA workflow от них не зависит.
