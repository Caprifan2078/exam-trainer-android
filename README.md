# Экзаменатор Android

Тренажёр демонстрационного экзамена: расчёт НМЦК, муниципальный бюджет и финансовый анализ. Самостоятельные задания, случайные исходные данные, проверка математических ответов.

Исходники и CI добавляются поэтапно. APK считается проверенным только после успешной сборки и теста запуска в Android-эмуляторе.
