# Экзаменатор Android — тренажёр демонстрационного экзамена

Учебное офлайн-приложение для Android. Программа показывает случайные исходные данные и **пустые поля**. Ученик самостоятельно выполняет расчёты, затем нажимает **«Проверить»**. Ответы и формулы раскрываются только по отдельной кнопке после проверки.

## Разделы
- **НМЦК:** новые товары и коммерческие предложения, средняя цена, выборочное стандартное отклонение, коэффициент вариации, итоговая НМЦК.
- **Муниципальный бюджет:** разнообразные статьи доходов и расходов, план/факт, исполнение в процентах, отклонения, дефицит/профицит.
- **Финансовый анализ:** вымышленная бухгалтерская отчётность, 23 финансовых показателя за два года в сложном режиме.

Есть три уровня сложности. Организации, цены и отчётные показатели синтетические. Программа не требует интернета после установки и не передаёт ответы на сервер. Это **учебная версия**, не официальный экзаменационный комплект. Точные нормативы и преподавательские методики подлежат согласованию.

## APK: сборка и установка на телефон
1. Открой вкладку [Actions](https://github.com/Caprifan2078/exam-trainer-android/actions) и выбери **Android APK: build and emulator check**.
2. Открой **последний успешный** запуск. Задания `build` и `android-emulator-smoke` должны быть зелёными.
3. В разделе **Artifacts** скачай `ExamTrainer-debug-APK`, распакуй ZIP на телефоне.
4. Установи `app-debug.apk`. Package ID — `io.github.caprifan2078.examtrainer`; это отдельное приложение, оно не должно заменять старые экспериментальные версии.

**Важное ограничение:** APK из CI подписывается временным debug-ключом runner. При повторной сборке ключ может измениться; обновление поверх предыдущего debug APK без удаления не гарантировано. Не храни критичные пользовательские данные в тестовой версии.

## Для разработки
- `app/src/main/java/.../MainActivity.java` — обычная Android WebView Activity.
- `app/src/main/assets/` — автономный интерфейс и генератор с эталонным математическим ключом.
- `scripts/test-engine.cjs` — тест 450 случайных вариантов и основных арифметических инвариантов.
- `.github/workflows/android.yml` — сборка Android SDK 35 / Gradle 8.9 и запуск в эмуляторе API 30.

```bash
node scripts/test-engine.cjs
gradle assembleDebug
```

**Условия успеха:** зелёные Gradle, тесты и эмулятор не заменяют испытание на реальном телефоне. Если приложение падает, открой в GitHub Actions шаг `Launch APK in Android emulator` и передай журнал ошибки.
